# 会议室管理系统

基于 SpringBoot 3.4.x 开发的企业级会议室管理解决方案，支持会议室资源管理、预约申请审批、会议签到、消息通知等全生命周期管理功能。

## 核心功能

- **会议室管理**：会议室信息维护、容量配置、设备管理、状态监控
- **预约管理**：在线预约申请、时间段冲突检测、审批流程、预约取消
- **会议签到**：扫码签到、迟到/缺席标记、签到统计
- **消息通知**：审批结果通知、会议提醒、取消通知
- **使用统计**：会议室利用率分析、预约趋势报表

## 技术栈

- SpringBoot 3.4.x
- MyBatis Plus
- H2 Database（开发环境）/ MySQL（生产环境）
- Redis（可选，用于缓存）
- Lombok
- Maven

## 快速开始

### 1. 环境准备

- JDK 17+
- Maven 3.6+

### 2. 运行项目

```bash
# 克隆项目
git clone <repo-url>

# 进入项目目录
cd meeting-room-management-system

# 编译项目
mvn clean install

# 运行项目
mvn spring-boot:run -pl web
```

### 3. 访问系统

启动后访问以下地址：

- **前端页面**: http://localhost:8080/
- **API文档**: http://localhost:8080/swagger-ui.html

## 功能操作流程说明

### 一、首页概览

#### 功能说明
首页展示系统核心数据概览，包括会议室总数、今日预约数、待审批数、未读通知数，以及最近预约列表。

#### 操作流程
1. 系统启动后，访问 http://localhost:8080/ 进入首页
2. 页面自动加载并展示：
   - **会议室总数**：当前系统中所有会议室的数量
   - **今日预约**：当前所有预约记录的总数
   - **待审批**：状态为"待审批"的预约数量
   - **未读通知**：用户未读的消息通知数量
   - **最近预约**：最近5条预约记录的列表

### 二、会议室管理

#### 功能说明
会议室管理模块支持会议室的增删改查，包括会议室名称、位置、容量、设备配置和状态管理。

#### 操作流程

##### 1. 查看会议室列表
1. 点击顶部导航栏的 **"🏛️ 会议室管理"** 标签
2. 页面显示所有会议室的列表，包含：
   - ID、名称、位置、容量
   - 设备信息（投影仪、白板、音响等）
   - 状态（可用/维护中/已停用）

##### 2. 筛选和搜索会议室
- **按状态筛选**：在状态下拉框中选择"可用"、"维护中"或"已停用"
- **搜索**：在搜索框中输入会议室名称或位置进行模糊搜索

##### 3. 新增会议室
1. 点击 **"➕ 新增会议室"** 按钮
2. 在弹出的表单中填写以下信息：
   - **会议室名称**：必填，如"会议室A"
   - **位置**：必填，如"1号楼101室"
   - **容量**：必填，可容纳人数
   - **状态**：选择"可用"、"维护中"或"已停用"
   - **设备**：可选，用逗号分隔，如"投影仪,白板,音响"
   - **描述**：可选，会议室的详细说明
3. 点击 **"保存"** 按钮完成添加

##### 4. 删除会议室
1. 在会议室列表中找到要删除的会议室
2. 点击操作列的 **"删除"** 按钮
3. 在确认对话框中点击 **"确定"**

### 三、预约管理

#### 功能说明
预约管理模块支持会议室预约申请、时间段冲突检测、审批流程和预约取消功能。

#### 操作流程

##### 1. 查看预约列表
1. 点击顶部导航栏的 **"📅 预约管理"** 标签
2. 页面显示所有预约记录的列表，包含：
   - 会议主题、会议室名称
   - 开始时间、结束时间
   - 参会人数、状态
   - 操作按钮

##### 2. 筛选预约记录
- **按状态筛选**：选择"待审批"、"已通过"、"已驳回"、"已取消"或"已完成"
- **按会议室筛选**：选择特定会议室查看其预约记录

##### 3. 新建预约
1. 点击 **"➕ 新建预约"** 按钮
2. 在弹出的表单中填写以下信息：
   - **选择会议室**：必填，从下拉列表选择可用会议室
   - **会议主题**：必填，如"产品需求评审会"
   - **会议目的**：必填，简要说明会议目的
   - **开始时间**：必填，选择会议开始时间（不能早于当前时间）
   - **结束时间**：必填，必须晚于开始时间
   - **参会人数**：必填，不能超过会议室容量
   - **申请人ID**：默认为1
3. 点击 **"提交预约"** 按钮

> **注意**：系统会自动检测时间段冲突，如果该时间段会议室已被预约，会提示错误。

##### 4. 审批预约（管理员操作）
1. 在预约列表中找到状态为 **"待审批"** 的预约
2. 点击操作列的 **"审批"** 按钮
3. 在审批对话框中：
   - 选择 **"通过"** 或 **"驳回"**
   - 如果选择驳回，需要填写 **驳回原因**
4. 点击 **"确认"** 按钮完成审批
5. 系统会自动给申请人发送审批结果通知

##### 5. 取消预约
1. 在预约列表中找到状态为 **"待审批"** 或 **"已通过"** 的预约
2. 点击操作列的 **"取消"** 按钮
3. 在确认对话框中点击 **"确定"**
4. 系统会自动发送取消通知

### 四、会议签到

#### 功能说明
会议签到模块支持签到登记、迟到/缺席自动标记和签到统计功能。

#### 操作流程

##### 1. 查看签到记录
1. 点击顶部导航栏的 **"✋ 会议签到"** 标签
2. 在 **"签到管理"** 区域的下拉框中选择要查看的会议
3. 页面显示：
   - **签到统计**：已签到人数、签到率
   - **签到列表**：每个签到者的用户ID、签到时间、状态、备注

##### 2. 手动签到
1. 在预约列表中找到状态为 **"已通过"** 的预约
2. 点击操作列的 **"签到"** 按钮
3. 在签到对话框中填写：
   - **用户ID**：签到用户的ID
   - **备注**：可选备注信息
4. 点击 **"签到"** 按钮

> **注意**：系统会根据签到时间自动判断状态：
> - 会议开始前或开始时签到：**已签到**
> - 开始后15分钟内签到：**已签到**
> - 开始15分钟后签到：**迟到**

##### 3. 扫码签到
1. 在 **"扫码签到"** 区域的下拉框中选择会议
2. 系统显示会议信息，用户可以：
   - 扫描系统生成的二维码进行签到
   - 或在前端页面手动输入签到信息

### 五、消息通知

#### 功能说明
消息通知模块提供审批结果通知、会议提醒和取消通知功能。

#### 操作流程

##### 1. 查看通知列表
1. 点击顶部导航栏的 **"🔔 消息通知"** 标签
2. 页面显示所有通知记录，按时间倒序排列
3. 未读通知会以 **浅蓝色背景** 高亮显示

##### 2. 标记为已读
- **单个已读**：点击任意通知即可自动标记为已读
- **全部已读**：点击 **"📖 全部已读"** 按钮，将所有未读通知标记为已读

##### 3. 通知类型说明

| 通知类型 | 触发条件 | 通知内容示例 |
|---------|---------|-------------|
| 审批结果通知 | 预约被审批通过或驳回 | "您的会议室预约已通过审批。" |
| 会议提醒 | 会议开始前30分钟 | "您预约的会议"产品评审会"将于14:00开始..." |
| 取消通知 | 预约被取消 | "您预约的会议"产品评审会"已被取消。" |

### 六、使用统计

#### 功能说明
使用统计模块提供会议室利用率分析和详细统计报表。

#### 操作流程

##### 1. 查看利用率统计
1. 点击顶部导航栏的 **"📈 使用统计"** 标签
2. 在 **"会议室利用率"** 区域：
   - 可选：选择 **开始日期** 和 **结束日期** 进行时间范围筛选
   - 点击 **"🔍 查询"** 按钮
3. 页面以 **进度条** 形式展示每个会议室的利用率

##### 2. 查看详细统计报表
在 **"详细统计报表"** 区域，每个会议室显示以下数据：

| 统计项 | 说明 |
|-------|------|
| 总预约数 | 该会议室的预约总次数 |
| 已完成 | 状态为"已完成"的预约数 |
| 已取消 | 状态为"已取消"的预约数 |
| 利用率 | 已完成预约数 / 总预约数 × 100% |

## 状态枚举说明

### 会议室状态 (RoomStatus)

| 状态码 | 状态名称 | 说明 |
|-------|---------|------|
| 0 | 可用 | 会议室正常可用，可以预约 |
| 1 | 维护中 | 会议室正在维护，暂不可用 |
| 2 | 已停用 | 会议室已停用，不可预约 |

### 预约状态 (ReservationStatus)

| 状态码 | 状态名称 | 说明 |
|-------|---------|------|
| 0 | 待审批 | 预约已提交，等待审批 |
| 1 | 已通过 | 预约已审批通过 |
| 2 | 已驳回 | 预约被驳回 |
| 3 | 已取消 | 预约已取消 |
| 4 | 已完成 | 预约已完成 |

### 签到状态 (SignInStatus)

| 状态码 | 状态名称 | 说明 |
|-------|---------|------|
| 0 | 未签到 | 用户尚未签到 |
| 1 | 已签到 | 用户已按时签到 |
| 2 | 迟到 | 用户迟到签到 |
| 3 | 缺席 | 用户缺席 |

### 通知类型 (NotificationType)

| 状态码 | 类型名称 | 说明 |
|-------|---------|------|
| 0 | 审批结果通知 | 预约审批通过或驳回时发送 |
| 1 | 会议提醒 | 会议开始前30分钟自动发送 |
| 2 | 取消通知 | 预约被取消时发送 |

## 常见问题

### Q1: 预约时提示"该时间段会议室已被预约"怎么办？
A: 请选择其他时间段或其他会议室。系统会自动检测同一会议室的时间段冲突。

### Q2: 为什么会议室状态显示"维护中"？
A: 管理员可以将会议室设置为维护状态，此时该会议室不可预约。请联系管理员或选择其他会议室。

### Q3: 签到时间有什么限制？
A: 签到需要在会议结束后30分钟内完成。超过签到截止时间将无法签到。

### Q4: 会议提醒是如何发送的？
A: 系统会在会议开始前30分钟自动发送会议提醒通知。该任务每5分钟执行一次检查。

### Q5: 如何切换到MySQL数据库？
A: 修改 `application-prod.yml` 配置文件，配置MySQL连接信息，然后将 `application.yml` 中的 `spring.profiles.active` 改为 `prod`。
